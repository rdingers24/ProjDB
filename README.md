# ProjDB

A simple Flask app that reads `majors.db`, shows a team dropdown, and displays the years each team won or finished runner-up.

## Run the app

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Start the server:

```bash
python app.py
```

3. Open `http://127.0.0.1:5000` in your browser.
